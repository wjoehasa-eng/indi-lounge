연결 설정

Apps Script 웹 앱 주소를 넣으면 실제 아카이브를 불러옵니다.

샘플 미리보기

가상의 샘플 데이터로 동작 중입니다.

주소는 이 브라우저(localStorage)에만 저장되고 다른 곳으로 전송되지 않습니다.

연결 방법

  1. apps-script/Code.gs를 새 Apps Script에 붙여넣고 웹 앱으로 배포합니다.
  2. 아카이브 JSON 파일 ID를 ARCHIVE_FILE_ID에 넣습니다.
  3. 배포된 /exec 주소를 위에 붙여넣고 저장합니다.

스크랩 카테고리

카테고리를 고르면 스크랩에 저장돼요.

카테고리 관리

스크랩을 나눠 담을 이름을 만들거나 지울 수 있어요.

카테고리를 지우면 그 안의 스크랩은 미분류로 옮겨집니다. 스크랩 자체는 지워지지 않아요.
