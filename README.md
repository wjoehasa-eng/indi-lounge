# 라운지 인기글 — 인디스쿨 라운지 인기글 아카이브 (PWA)

인디스쿨 라운지의 인기글을 **시간대별 · 일간 · 주간 · 월간**으로 모아 보고, **과거 시간대·날짜·주차·월**까지 되돌려 조회하는 모바일 우선 웹앱입니다.
다음(Daum) 인기글 화면의 구조(기간 선택 팝업 + 순위 카드 리스트)를 계승하고, 디자인은 토스(Toss) 스타일로 새로 만들었습니다.

- 공개 저장소용 **빈 껍데기** 앱입니다. 개인정보·실제 시트/스크립트 URL·인디스쿨 계정 정보는 **0건**이며, 처음 열면 가상의 **샘플 데이터**로 바로 동작합니다.
- `⚙ 설정`에 Apps Script `/exec` 주소를 넣으면 내 구글 드라이브 아카이브에서 실제 데이터를 불러옵니다.

## 화면

| 화면 | 설명 |
| --- | --- |
| 인기글 목록 | 상단 세그먼트(시간대별/일간/주간/월간), 기간 바, 검색, 필터 칩, 순위 카드 |
| 기간 선택 | 바텀시트 라디오 목록으로 과거 시간대·날짜·주차·월 즉시 이동 |
| 글 상세 | 전체 본문·작성자·시각·좋아요/댓글/스크랩·이미지·원문 링크·스크랩 카테고리 칩 |
| 전체 스크랩함 | 날짜·기간과 상관없이 저장한 모든 글 + 카테고리 필터 칩 + 카테고리 관리 |
| 카테고리 선택 | 카드 `🔖`을 누르면 뜨는 토스 스타일 바텀시트 (칩 선택·새 카테고리·해제) |
| 연결 설정 | Apps Script URL 저장·연결 확인·샘플로 되돌리기 (localStorage) |

## 파일 구조

```
indi-lounge/
├─ index.html                 # 앱 전체 (HTML + CSS + JS)
├─ data/
│  └─ samples.js              # 샘플 데이터 (window.SAMPLE_DATA)
├─ assets/
│  ├─ fonts/PretendardVariable.woff2   # Pretendard (OFL) 오프라인 내장
│  └─ img/                    # 샘플 썸네일(t01~t10) + PWA 아이콘
├─ manifest.webmanifest       # PWA 매니페스트
├─ sw.js                      # 서비스 워커 (앱 껍데기 캐시, 외부 API는 캐시 안 함)
├─ apps-script/Code.gs        # 구글 드라이브 JSON 아카이브 백엔드 템플릿
└─ README.md
```

모든 경로는 상대 경로(`./`)라서 저장소 이름이나 하위 경로에 상관없이 그대로 동작합니다.

## GitHub Pages로 열기

이 저장소는 GitHub Pages에 바로 올릴 수 있는 정적 사이트입니다.

1. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 지정합니다.
2. 잠시 뒤 아래 주소에서 열립니다: <https://wjoehasa-eng.github.io/indi-lounge/>
3. 휴대폰 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 설치됩니다.

## 로컬에서 실행

```bash
git clone https://github.com/wjoehasa-eng/indi-lounge.git
cd indi-lounge
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```

`file://`로 열어도 화면은 보이지만, 서비스 워커·PWA 설치는 `http(s)`에서만 동작합니다.

## 실제 아카이브 연결하기

1. **아카이브 JSON 만들기**
   - 구글 드라이브에 빈 파일 `lounge-archive.json`을 만들고 파일 ID를 복사합니다. (또는 Apps Script 편집기에서 `createArchiveFile()` 실행)
2. **Apps Script 배포**
   - <https://script.google.com> → 새 프로젝트 → `apps-script/Code.gs` 전체를 붙여넣습니다.
   - `ARCHIVE_FILE_ID`에 위 파일 ID를, 수집 스크립트로 쓰기를 허용하려면 `WRITE_TOKEN`에 임의의 긴 문자열을 넣습니다.
   - 배포 → 새 배포 → 유형 **웹 앱**, 실행 사용자 **나**, 액세스 **링크가 있는 모든 사용자**.
3. **앱에 연결**
   - 배포된 `.../exec` 주소를 앱 `⚙ 설정`에 붙여넣고 `저장하고 연결`을 누릅니다.
   - 연결되면 배지가 `연동됨`으로 바뀌고, 주소는 그 브라우저의 `localStorage`에만 저장됩니다.
   - `샘플 데이터로 되돌리기`로 언제든 초기 상태로 돌아갑니다.

### 읽기 API

| 요청 | 응답 |
| --- | --- |
| `GET ?action=index` | `{ ok, periods: { hourly:[{key,label,caption,collectedAt,count}], daily:[…], weekly:[…], monthly:[…] } }` |
| `GET ?action=list&mode=hourly&key=2026-11-25-18` | `{ ok, label, caption, collectedAt, posts:[…] }` |
| `GET ?action=ping` | `{ ok, at }` |
| `&callback=함수명` | JSONP 응답 (CORS가 막히는 환경 대비) |

### 쓰기 API (수집 스크립트용)

```http
POST {exec}
{ "token": "…", "action": "put", "mode": "daily", "key": "2026-11-25",
  "label": "11월 25일 (수)", "caption": "오늘 · 오전 10:20 기준", "collectedAt": "오전 10:20",
  "posts": [ { "id": "2246…", "author": "익명", "body": "…", "at": "2026-11-25T08:12:00+09:00",
               "likes": 42, "comments": 5, "scraps": 2, "image": "", "isNew": true } ] }
```

`action: "append"`이면 기존 글과 `id` 기준으로 합칩니다. 순위는 앱이 좋아요 순으로 다시 매깁니다.

### 아카이브 파일 형식

```json
{
  "updatedAt": "2026-11-25T10:20:00+09:00",
  "periods": {
    "hourly":  { "2026-11-25-18": { "label": "11월 25일 (수) 18시", "caption": "15:00~17:59 · TOP 30",
                                   "collectedAt": "오후 6:00", "posts": [] } },
    "daily":   { "2026-11-25": { "label": "11월 25일 (수)", "caption": "오늘 · 오전 10:20 기준",
                                 "collectedAt": "오전 10:20", "posts": [] } },
    "weekly":  { "2026-11-W4": { "label": "11월 4주차", "caption": "11.23~11.29", "posts": [] } },
    "monthly": { "2026-11":    { "label": "2026년 11월", "caption": "11.01~11.25", "posts": [] } }
  }
}
```

기간 키는 `hourly` = `YYYY-MM-DD-HH`(HH는 12·15·18 — 09~11시 글은 12시, 12~14시 글은 15시, 15~17시 글은 18시), `daily` = `YYYY-MM-DD`, `weekly` = `YYYY-Wnn`, `monthly` = `YYYY-MM` 입니다.

## 기능 요약

- **세그먼트 탭**: 시간대별 / 일간 / 주간 / 월간
- **시간대별 탭**: 12시(09:00~11:59) · 15시(12:00~14:59) · 18시(15:00~17:59) 직전 3시간 인기글 TOP 30, 기간 바텀시트에서 과거 시간대 바로 선택 (수집 전이면 안내 후 일간으로 이동)
- **기간 바**: `‹` `›` 이동, 가운데를 누르면 바텀시트 라디오 목록(과거 시점 바로 선택)
- **순위 카드**: 01~03 토스 블루, 04~ 회색, 새 글 빨간 점, 이미지 글은 정사각 썸네일
- **검색**: 본문·작성자 실시간 필터, 결과 없음 상태
- **필터**: 전체 / TOP 15 / 스크랩(전체 스크랩함)
- **읽음 표시**: 상세를 연 글은 카드가 옅게 표시 (`localStorage`)
- **전체 스크랩함**: `스크랩 N` 칩을 누르면 날짜·주차·월과 상관없이 저장한 모든 글이 한곳에 모임 (배지 N = 전체 스크랩 개수)
- **스크랩 카테고리**: `미분류`·`학급운영`·`수업·자료`·`공문·행정`·`학부모·상담`·`꿀팁·기타` 기본 제공, `+ 새 카테고리`로 추가(최대 12개)·삭제(내용은 미분류로 이동)
- **카테고리 선택**: 카드 `🔖` → 바텀시트에서 칩 선택, 상세 시트 안에서도 칩으로 바로 변경
- **상세 시트**: 전체 본문, 작성자, 작성 시각, 좋아요·댓글·스크랩, 이미지, `인디스쿨에서 원문 보기`
- **설정 시트**: `/exec` URL 저장·연결 확인·초기화, 연결 방법 안내
- **PWA**: 오프라인 캐시, 홈 화면 설치, 안전 영역(safe-area) 대응
- **접근성**: 시트 열림 시 포커스 이동·ESC 닫기·Tab 순환, 카드 키보드 열기

## 스크랩 저장 형식

브라우저 `localStorage`의 `indi_lounge_scraps_v1` 한 곳에 모읍니다. 글 내용 스냅샷을 함께 저장하므로 다른 날짜로 이동하거나 새로고침해도 전체 스크랩함에서 글이 그대로 열립니다.

```json
{
  "v": 1,
  "categories": ["미분류", "학급운영", "수업·자료", "공문·행정", "학부모·상담", "꿀팁·기타"],
  "items": [
    { "id": "224600112543", "body": "…", "author": "도담쌤", "createdAt": "2026-11-25T09:36:00+09:00",
      "likes": 261, "comments": 50, "scraps": 5, "image": "",
      "category": "학급운영", "savedAt": "2026-11-25T11:40:12.345Z", "sourceLabel": "11월 25일 (수)" }
  ]
}
```

- 예전 버전의 `lounge.saved`(ID만 저장)는 처음 열 때 자동으로 새 형식으로 옮기고, 글 내용을 아카이브에서 찾아 채웁니다.
- 저장 위치·카테고리 이름은 그 브라우저에만 남고 서버로 보내지 않습니다.

## 개인정보·보안 원칙

- 저장소에 실제 게시물·작성자·계정·시트 ID·웹앱 URL이 **없습니다**. 샘플 글은 모두 가상이며 글 번호도 실제 글과 연결되지 않습니다.
- 연결 주소는 브라우저 `localStorage`에만 저장되고 서버로 전송되지 않습니다.
- 서비스 워커는 같은 출처의 앱 껍데기만 캐시합니다. `script.google.com` 등 외부 아카이브 응답은 캐시하지 않습니다.
- 샘플 데이터의 썸네일은 생성 이미지이며 인물·학교 정보가 없습니다.

## 검증 (2026-11-25)

- 로컬 `python3 -m http.server` + Playwright Chromium
- 모바일 `390×844` / 데스크톱 `1280×800`
- 콘솔·페이지 에러 **0건**, 가로 넘침(`scrollWidth <= clientWidth`) **0건**
- 시간대별 탭 51/51 통과 (모바일 390·360 / 데스크톱 1280): 4탭 한 줄 배치·글자 잘림 0, 시간대별 18시/15시/12시 라벨·부제, 30위 카드, 기간 바텀시트 라디오 3개·선택 이동, 이전/다음 경계, 상세 `시간대별 N위`, 연동 모드(hourly 있음/비어 있음) 표시
- 기본 기능 63/63 통과: 탭 전환, 기간 바텀시트 열기·선택, 이전/다음 이동·경계 비활성, 상세 열기·닫기, 검색·필터·스크랩·읽음, 설정 모달, 상태 저장, 연동 모드(가상 엔드포인트), 연결 실패 시 샘플 폴백
- 전체 스크랩함·카테고리 94/94 통과: 카드 `🔖`→카테고리 선택, 상세 저장·카테고리 변경, 전체 스크랩함 전환(기간 바 숨김), 카테고리 필터, 새 카테고리 추가·중복 방지, 카테고리 삭제 시 미분류 이동, 다른 날짜로 이동해도 전체 스크랩 유지, 새로고침 후 유지, 구버전 `lounge.saved` 마이그레이션
- 오프라인 재접속에서 50개 카드·폰트·이미지 정상 로드
- 스크린샷: `01-일간-목록.png` ~ `10-카테고리-삭제.png`
